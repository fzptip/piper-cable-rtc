## 本次实际改动

1. 新目录只含当前源码与精选文档，未复制旧 Git 仓库、原始数据、权重或备份。
2. 将 v3 参数整理为独立入口；按脚本目录启动客户端，支持本地 Conda/ROS 配置，默认录像目录跟随代码目录。
3. 服务器入口支持通过环境变量/命令行指定 checkpoint 和 assets 基目录；仍沿用原训练配置、动作变换、采样和 RTC guidance。
4. 删除旧源码快照、旧启动脚本及依赖旧 Git 提交的 baseline 回归入口；保留当前实现的回归测试和第三方许可证。
5. 历史插值回放脚本支持显式输入路径，继续限制为对应的历史数据，输出放入独立目录。

队列、插值器和诊断记录器与原 v3 文件逐字节比较；差异情况记录于来源清单。客户端主文件只改默认录像路径，控制逻辑未改。

本轮复用历史模型输出，未在修正前缀下重新推理，没有动作到图像/接触的闭环反馈。新目录部署后的真实频率、跟踪误差、接触表现和任务成功率仍需操作者后续实验验证。
